# TaskFlow – سامانه مدیریت و پیگیری وظایف روزانه

## ۱. معرفی پروژه

TaskFlow یک سامانه ساده برای مدیریت و پیگیری وظایف روزانه است. هدف از طراحی این برنامه، کمک به کاربران برای ثبت وظایف، اولویت‌بندی فعالیت‌ها و پیگیری وضعیت انجام آن‌هاست.

کاربر می‌تواند وظایف خود را ثبت کند، اطلاعات آن‌ها را تغییر دهد، وظایف موردنظر را جست‌وجو کند و با استفاده از فیلترها، وظایف را بر اساس وضعیت و اولویت مشاهده کند.

## ۲. امکانات پروژه

- نمایش تعداد کل وظایف
- نمایش تعداد وظایف در انتظار، در حال انجام و تکمیل‌شده
- افزودن وظیفه جدید
- ویرایش اطلاعات وظایف
- حذف وظایف
- تعیین اولویت وظایف در سه سطح زیاد، متوسط و کم
- تعیین وضعیت وظایف
- ثبت تاریخ ایجاد و تاریخ سررسید
- جست‌وجوی وظایف بر اساس عنوان
- فیلتر وظایف بر اساس وضعیت و اولویت
- شناسایی و نمایش وظایف عقب‌افتاده
- رابط کاربری واکنش‌گرا و فارسی

## ۳. فناوری‌های استفاده‌شده

- **Python:** زبان برنامه‌نویسی اصلی پروژه
- **Flask:** فریم‌ورک مورد استفاده برای پیاده‌سازی بخش سمت سرور
- **SQLite:** پایگاه داده برای ذخیره اطلاعات وظایف
- **HTML:** طراحی ساختار صفحات
- **CSS:** طراحی ظاهر و استایل صفحات
- **Bootstrap:** استفاده از امکانات آماده برای طراحی رابط کاربری واکنش‌گرا

## ۵. توضیح فایل‌های اصلی

- **app.py:** شامل مسیرهای برنامه و منطق اصلی مدیریت وظایف است.
- **database.py:** مسئول ایجاد و اتصال به پایگاه داده SQLite است.
- **database.db:** فایل پایگاه داده و محل ذخیره اطلاعات وظایف است.
- **requirements.txt:** شامل کتابخانه‌های موردنیاز برای اجرای پروژه است.
- **templates:** شامل فایل‌های HTML صفحات مختلف برنامه است.
- **static/css/style.css:** شامل کدهای مربوط به طراحی ظاهری صفحات است.

## ۶. نحوه نصب و اجرای پروژه

### مرحله اول: نصب Python

برای اجرای پروژه باید Python روی سیستم نصب باشد.

### مرحله دوم: نصب کتابخانه‌های موردنیاز

ترمینال را در پوشه اصلی پروژه باز کنید و دستور زیر را اجرا کنید:

```bash
python -m pip install -r requirements.txt
```

### مرحله سوم: اجرای برنامه

برای اجرای برنامه دستور زیر را وارد کنید:

```bash
python app.py
```

### مرحله چهارم: ورود به سامانه

پس از اجرای موفق برنامه، آدرس زیر را در مرورگر وارد کنید:

http://127.0.0.1:5000

با باز شدن این آدرس، صفحه داشبورد سامانه TaskFlow نمایش داده می‌شود.

## ۷. ساختار پایگاه داده

در این پروژه از پایگاه داده SQLite استفاده شده است. اطلاعات وظایف در جدولی با نام `tasks` ذخیره می‌شوند.

این جدول شامل فیلدهای زیر است:

| نام فیلد | توضیحات |
|---|---|
| id | شناسه اختصاصی هر وظیفه |
| title | عنوان وظیفه |
| description | توضیحات وظیفه |
| priority | اولویت وظیفه |
| status | وضعیت انجام وظیفه |
| created_at | تاریخ ایجاد وظیفه |
| due_date | تاریخ سررسید وظیفه |

## ۸. محدودیت‌های پروژه

- سامانه فاقد سیستم ورود و ثبت‌نام کاربران است.
- اطلاعات در پایگاه داده محلی SQLite ذخیره می‌شوند.
- امکان ارسال اعلان و یادآوری از طریق پیامک یا ایمیل وجود ندارد.
- برنامه برای استفاده محلی و مدیریت وظایف طراحی شده است.

## ۹. نتیجه‌گیری

در این پروژه یک سامانه ساده برای مدیریت و پیگیری وظایف روزانه با استفاده از Python و Flask طراحی و پیاده‌سازی شده است.

قابلیت‌های اصلی شامل ثبت، ویرایش، حذف، جست‌وجو، فیلتر و نمایش وضعیت وظایف هستند. همچنین امکان تعیین اولویت و تاریخ سررسید و شناسایی وظایف عقب‌افتاده نیز در برنامه پیاده‌سازی شده است.

عملکرد قابلیت‌های اصلی برنامه به‌صورت عملی مورد آزمایش قرار گرفته و نتایج تست‌ها نشان می‌دهد که بخش‌های اصلی سامانه مطابق انتظار کار می‌کنند.
